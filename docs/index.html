Install and work in minutes

Pick the Windows path that fits. Both open the same application.

1 · Setup.exe (recommended)

  1. Open the latest GitHub release
  2. Download PDFMaster-*-Setup.exe
  3. Run the installer (Start Menu + desktop shortcut)
  4. Launch PDFMaster and press Ctrl+O

2 · Portable ZIP

  1. Download PDFMaster-*-win64.zip
  2. Extract anywhere (USB / local folder)
  3. Run PDFMaster.exe — no install required

From source or build Setup.exe yourself — see INSTALL.md.

After install, use QUICKSTART.md for first-run steps (Review tab, markup, save).
