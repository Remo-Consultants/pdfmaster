The PDF stays on the device.

PDFMaster is a Windows workspace for reading, marking, editing, organizing, and reviewing PDFs, plus a phone reader for iOS and Android. Every file is opened from local storage. Nothing in the app uploads a document.

One window, one document at a time in focus

The Windows app is a desktop workspace. The phone app is a reader. They share the name and the rule that the file stays local.

Home

Open, then work

The empty window is an open card you can drop a PDF onto. Recent files sit in a pane on the right. The work list and the tool rail stay hidden until a document is open.

Modes

Seven ways to work

With a PDF open, the sidebar switches among Home, Markup, Edit, Organize, Review, Sign, and View. Each mode shows its own tools on the rail above the page.

Tabs

Several files, separate state

Each open PDF has its own tab, zoom, page, and undo history. Switching tabs returns you to that document’s place.

What PDFMaster can do

Editing, redaction, page structure, OCR, compare, security, and batch run on Windows. The phone opens, reads, searches, and shares a local file.

Continuous pages, fit width or page, thumbnails, bookmarks, properties, and full-document search.

Local files

Open from the device. Recent lists store paths on that device. A failed open tells you whether the file is missing, too large, or not a PDF.

Saves you can trust

View · Windows

Read the page as a page

Pages scroll continuously with a soft shadow so the edge stays visible. The Windows workspace stays on a light studio theme: a lavender canvas, white panels, and an indigo accent. The phone follows the device’s light or dark appearance.

On the page

  • Zoom from 25% to 400%. The slider moves in 10% steps. Hold Ctrl and scroll the mouse wheel to zoom toward the pointer. Fit width and fit page are on the rail.
  • Page spinner, previous and next, first and last page.
  • Thumbnail strip (F9) to jump. The same dock has a Bookmarks tab when the file has an outline.
  • Properties panel (F10). Text extract panel (Ctrl+T).
  • Search the whole document (Ctrl+F) and a search field in the top bar.
  • Files up to 500 MB. The header is checked for a PDF signature before the file is treated as a PDF.
Markup · Windows

Mark the document, then undo it

Markup tools live on the Markup rail. Colour applies to the current tool. Undo and redo cover the edit history of that tab.

Marks

  • Highlight, underline, and strikeout on text.
  • Sticky notes, and delete a selected annotation.
  • Freehand pen and rectangle shapes.
  • Eight colours: yellow, green, blue, pink, orange, red, black, white.

Watermarks and stamps

  • Text watermark with size, angle, opacity, and a page range: all pages, the current page, or a span.
  • Rubber stamps: DRAFT, CONFIDENTIAL, APPROVED, REJECTED, VOID, COPY, FINAL, FOR REVIEW, or your own wording.
  • Image stamps for a logo or a signature image.
Edit · Windows

Change what is in the file

Text in a PDF sits in fixed positions. When you replace it, PDFMaster shrinks the type until it fits, down to a minimum readable size, and tells you if the original font was missing and a standard face was used.

Content

  • Add text, edit existing text, and add an image (PNG, JPEG, BMP, GIF).
  • Find and replace across the document (Ctrl+H).
  • Erase an area. Fill existing form fields (Ctrl+Shift+F). If the file has no fields, the app says so.
  • Flatten annotations or form fields into the page content.
  • Standard faces available without embedding: Helvetica, Times, and Courier, including bold and italic variants.

Redaction

  • Draw the areas to remove, then apply them.
  • Applying a redaction deletes the text and images underneath. The saved file does not keep that content for copy and paste.
  • The cleared area is filled so the removal is visible on the page.
Organize · Windows

Reshape the page list

The Page Organizer (Ctrl+Shift+O) and the Organize rail change the structure of the open file. Rotate also sits on the rail for the current page.

Page organizer

  • Drag pages into a new order, or move one page up, down, to the top, or to the bottom.
  • Reverse the whole order. Duplicate a page. Delete a page — the last remaining page cannot be deleted.
  • Rotate left or right, on the current page or from the organizer.
  • Insert a blank page. Import pages from another PDF at a chosen position.
  • Merge other PDFs into the open file, appended or inserted.
Sign · Windows

Place a signature on the page

Sign stores one signature on this PC and stamps that image into the PDF where you drag. It is the appearance of a signature. It does not attach a certificate.

How you sign

  • Create a signature by drawing it, typing a name, or importing an image.
  • A typed name can use Script, Handwritten, Brush, Classic, or Formal. The preview uses a matching font installed on this PC.
  • PDFMaster keeps that signature in ~/.pdfmaster/signatures and reuses it until you replace it.
  • On the Sign rail, drag a box on the page. The saved signature is placed in that box.
  • If you have not created one yet, Place opens the same editor first.
Review · Windows

Search, read scans, compare, inspect

Review gathers the tools that look across a document or a folder: search, OCR, compare, PDF/A, and batch. They run on this PC.

Search and text

  • Find text in the open PDF and move through hits.
  • Extract the text layer into a panel you can read beside the page.

OCR

  • The searchable text layer uses Tesseract, which ships inside PDFMaster. Languages include English, German, French, Spanish, Italian, Portuguese, Simplified Chinese, and Japanese. EasyOCR is an optional extra engine when that package is installed.
  • Resolution from 72 to 600 DPI, default 300. Scope is the current page, all pages, or a range.
  • Write an invisible text layer so the scan can be searched. Skip pages that already have text.
  • Straighten a crooked scan, which replaces that page with the straightened image. Turn sideways pages upright.
  • Optionally save a PDF/A-2 copy with the Ghostscript build that ships inside PDFMaster.
  • Copy the recognized text from the OCR dialog.

Compare

  • Page-by-page text difference against another PDF: equal, changed, only in the left file, or only in the right file.
  • Each changed page shows a similarity score and a text diff.
  • Optional rendered-page comparison adds a visual similarity score.

PDF/A inspection

  • Reads whether the file declares PDF/A, which part and conformance it names, whether an OutputIntent is present, the PDF version, and the findings PDFMaster can see in the file.

Batch a folder

  • Compress each PDF and report the size change.
  • Merge the PDFs in a folder into one file.
  • Extract text from each file.
  • Convert each PDF to images.
Security, print, export · Windows

Lock a copy, print it, or save pages as images

On Windows, a password-protected file is reported as encrypted and is not opened. Set Password and Remove Password work on a document you can already open, and they write a new file.

Security

  • Security info shows encryption, user and owner passwords, the method, and whether print, copy, and annotation are allowed.
  • Set a user password and an owner password on a new copy.
  • Remove a password by saving an unlocked copy.
  • Place an empty signature field on the page. That field is a placeholder. The ink you draw, type, or import is placed from the Sign mode.

Print and export

  • Print through the system printer (Ctrl+P) and open a preview (Ctrl+Shift+P).
  • Export pages as PNG or JPEG (Ctrl+Shift+E) at 72, 150, 300, or 600 DPI. The default is 150. Print rendering caps at 300 DPI.
iOS and Android

A reader that stays on the phone

The phone app opens, reads, searches, and shares PDFs already on the device. Editing, redaction, page organization, OCR, compare, and batch are part of the Windows workspace.

On the phone

  • Open a PDF with the system document picker. Recent files list the name and the last time you opened them.
  • Empty home explains that files stay on this device.
  • A locked PDF asks for a password. A wrong password stays on that prompt. The file opens only after the password is accepted.
  • Continuous scroll, pinch zoom from 25% to 400%, fit width, and a page indicator.
  • Thumbnail sheet to jump to a page. In-document search, case-insensitive, with previous and next match.
  • Share sends a copy through the system share sheet.
  • The same checks as Windows: missing file, unreadable file, not a PDF, or larger than 500 MB.
  • Light and dark follow the phone’s system setting.

Install PDFMaster on Windows

Windows 10 or 11, 64-bit. The installer and the portable zip open the same application. The phone app is built from the Flutter project in this workspace for iOS and Android.

Setup.exe

  1. Open the latest release.
  2. Download PDFMaster-*-Setup.exe.
  3. Run the installer. It adds a Start menu entry and a desktop shortcut.
  4. Launch PDFMaster and press Ctrl+O, or drop a PDF on the home card.

Portable ZIP

  1. Download PDFMaster-*-win64.zip.
  2. Extract it to a local folder or a USB drive.
  3. Run PDFMaster.exe.

Source installs and building the installer are documented in INSTALL.md. First-run steps are in QUICKSTART.md.

OCR and the PDF/A-2 copy use Tesseract and Ghostscript included with the app. A source checkout fetches those files with scripts/fetch_bundled_tools.py. Logs are written to ~/.pdfmaster/logs/pdfmaster.log.

From source: Python 3.10 or newer, PySide6, PyMuPDF, pypdf, Pillow, and cryptography.

Open a PDF on this machine.

Download the Windows release. Markup, redaction, organize, review, and batch are in that app. The phone build reads the file where it already lives.
